🚀 QUICK START
================================================================================

1. INSTALL DEPENDENCIES
   pnpm install
   (All dependencies already listed in package.json)

2. CREATE ENVIRONMENT FILE
   cp .env.example .env.local
   
   Fill in:
   - NEXT_PUBLIC_SUPABASE_URL
   - NEXT_PUBLIC_SUPABASE_ANON_KEY
   - RESEND_API_KEY

3. SET UP DATABASE
   - Create Supabase account
   - Run schema.sql in SQL editor
   - Enable email authentication

4. RUN DEVELOPMENT SERVER
   pnpm dev
   
   Open: http://localhost:3000

5. TEST FEATURES
   - Register at /auth/register
   - Login at /auth/login
   - Access dashboard at /dashboard
   - Admin panel at /admin/login

🔄 APPLICATION FLOWS
================================================================================

REGISTRATION FLOW:
User → Fills form → Supabase creates auth user → Database creates profile
→ Email verification sent → User clicks link → Account ready

LOGIN FLOW:
User → Enters credentials → Supabase verifies → OTP sent via Resend
→ User enters 6-digit code → Session created → Dashboard access

BITCOIN DEPOSIT FLOW:
User → Views deposit page → QR code displayed → Scans with wallet
→ Sends Bitcoin → Blockchain confirms → Balance updated

WITHDRAWAL FLOW:
User → Requests withdrawal → Amount/address validated → Request created
→ Admin processes → Funds transferred → Status updated

ADMIN MANAGEMENT:
Admin → Logs in → Views member list → Edits balance/status
→ Freezes/deletes accounts → Manages wallets
